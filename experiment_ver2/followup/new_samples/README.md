# Frozen new original questions

These are question inputs, **not generated answers, completed human review, or new experiment results**. Selection used seed 20261018 and the protocol fingerprint saved in each manifest. Do not resample based on outcomes. Do not give gold answers or this directory to the blinded paraphrase reviewers.

- `nq/`: 1,800 original questions selected from the 3,610-row NQ-open development pool after excluding all 450 previously exposed originals. Source: [EfficientQA NQ-open](https://github.com/efficientqa/nq-open), derived from [Natural Questions](https://github.com/google-research-datasets/natural-questions) (Kwiatkowski et al., 2019) and the open-domain variant (Lee et al., 2019). The manifest identifies the exact downloaded bytes.
- `hotpotqa/`: 3,500 original questions selected from 7,405 fullwiki validation rows. Source: [HotpotQA](https://hotpotqa.github.io/) (Yang et al., EMNLP 2018), distributed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/); this reformatted subset retains that data license. The original CMU HTTP and HTTPS endpoints timed out. We used the [hotpotqa/hotpot_qa copy](https://huggingface.co/datasets/hotpotqa/hotpot_qa) at revision `1908d6afbbead072334abe2965f91bd2709910ab`, fullwiki validation Parquet, read with PyArrow 26.0.0. Conversion kept row order, selected `id/question/answer/type/level`, and renamed `id` to `_id`. No retrieval context or supporting facts were imported into the model inputs.

For both datasets, all 450 archived original questions, source positions/IDs, and gold-answer lists were checked against the recovered source pools. This establishes compatibility with the visible archived sample; it is not proof that every row of a mirror is identical to an unavailable original file or that no undisclosed experiment has exposed other questions. Normalized-text and original-ID overlap with the available archive is excluded; semantic overlap remains a limitation.

See [source validation and conversion fingerprints](../evidence/source_validation.json). `originals.jsonl` is the frozen output of sampling; `manifest.json`, `exposure_inventory.json`, and `SHA256.json` preserve selection and exclusion evidence. The complete raw pools and downloaded Parquet remain local under `experiment_ver2/runs/source_pools`.

Run the next stage with `--sample experiment_ver2/followup/new_samples/nq` (or `hotpotqa`), using the unchanged protocol. Each original remains in the evaluation even if automatic paraphrase screening retains fewer than two variants. Actual generation is still pending runtime assets.
